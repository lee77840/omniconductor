# Research

Store durable research notes here as:

`docs/research/YYYY-MM-DD-<topic>.md`

Record source links, access dates, verified facts, inferences, and unresolved
questions. Research that directly changes architecture should also produce or
update the corresponding ADR.

An existing plugin-specific research folder is not a CONDUCTOR path override.
Only the artifact-class table in `docs/INDEX.md` may declare a different project
location.
