# Implementation plans

Store reviewable implementation plans here as:

`docs/plans/YYYY-MM-DD-<topic>.md`

A plan records scope, architecture fit, ordered tasks, verification, and stop
conditions. `docs/PLANS.md` is the strategic or phase roadmap; it is not a folder
for per-change implementation detail.

An existing plugin-specific plan directory is not a CONDUCTOR path override.
Only the artifact-class table in `docs/INDEX.md` may declare a different project
location.
